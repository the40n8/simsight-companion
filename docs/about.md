# About

SimSight Companion is an independent project based on
[TS4 Access](https://github.com/LeonianUniverse478/Sims4Access), the
screen-reader mod for The Sims 4. It was started so a blind player and a
sighted player could play together on a Mac, and grew a phone app and a
Windows version.
